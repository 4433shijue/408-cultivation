# 24 道基础题复核记录

复核方式：逐题核对题干自足性、四选一唯一性、答案下标与解析，涉及数值题重新计算。此记录由开发过程整理，不冒充人工专家签字、教材页码或当年考纲认证。所有题均为基础概念示例。

| ID    | 答案 | 核对依据                                           |
| ----- | ---- | -------------------------------------------------- |
| ds-01 | A    | 已有容量足够，顺序表尾部插入不移动元素，O(1)。     |
| ds-02 | B    | 栈后进先出，B 先弹出。                             |
| ds-03 | C    | 队列先进先出，A 先离队。                           |
| ds-04 | D    | 折半查找每轮区间减半，最坏 O(log n)。              |
| ds-05 | B    | 非根结点各有一条父边，共 n−1。                     |
| ds-06 | B    | 广度优先按发现顺序处理，使用队列。                 |
| os-01 | B    | 程序为静态指令，进程为执行过程。                   |
| os-02 | B    | 等待 I/O 进入阻塞；时间片耗尽通常进入就绪。        |
| os-03 | D    | 死锁必要条件为互斥、请求保持、不可剥夺、循环等待。 |
| os-04 | C    | 按字节编址，4 KiB=4096 字节，需要 12 位偏移。      |
| os-05 | D    | 时间片结束但仍可运行，进入就绪队列。               |
| os-06 | B    | 单个互斥许可，信号量初始为 1。                     |
| cn-01 | B    | IP 提供尽力而为无连接数据报服务。                  |
| cn-02 | C    | 二层以太网交换机按目的 MAC 转发。                  |
| cn-03 | C    | 典型 TCP 建连 SYN、SYN+ACK、ACK 三次握手。         |
| cn-04 | B    | IPv4 地址长度为 32 位。                            |
| cn-05 | A    | DNS 查询域名资源记录，包含地址解析。               |
| cn-06 | B    | UDP 四个 16 位字段，共 8 字节。                    |
| co-01 | B    | 运算器完成算术与逻辑运算。                         |
| co-02 | D    | 2^10=1024 个字节地址。                             |
| co-03 | C    | 8 位无符号最大为 2^8−1=255。                       |
| co-04 | B    | 8 位补码范围 −128 至 127。                         |
| co-05 | A    | 缓存利用时间与空间局部性。                         |
| co-06 | A    | PC 通常保存下一条待执行指令地址。                  |

发现争议时先举报退池，复核后决定恢复或废弃，不改写玩家历史记录。
