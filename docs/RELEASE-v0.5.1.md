# v0.5.1 交付与迁移

本轮完成逐幕序章、分姓/名与随机起名、设置改名、恋爱后的亲昵称呼、体力系统、纵向山行地图与 NPC 图集裁切修复。

## 规则

- 体力初始/上限5，现实每小时恢复1，离线继续。仅首次通过新关恢复1，成功重玩不增不减；失败扣1。达到上限不累计额外恢复次数。
- 地图、切换页面、关闭后重开保留当前试炼。换关前明确确认放弃，扣1；体力为0不允许新开局，其他玩法不受影响。
- 结算后棋盘停止接收输入；按钮直接进入下一关，末关提供重游。结算和开局使用现有跨标签锁，按试炼ID防重复处理。
- 姓可留空，最多4字；名1—8字。随机取名在本地执行。复姓保留完整。
- 确认恋爱且明确填写了名后，AI提示词允许只叫名。改名后下次请求使用最新姓名；旧故事、旧聊天不改写，不猜测旧存档的姓氏。

## 存档

沿用版本4与原localStorage键，增加 `revision: 1`、`nameParts`、`stamina`。旧v4读取时先保留 `lingtian-408-save-v4-before-identity-stamina` 原始备份，再补充体力5、未拆分姓名。旧败局不追扣体力。v1—v3继续经现有迁移路径升级。

游戏设置里的完整导入/导出保留姓名、体力、课程、聊天和故事。题库仍独立导出。纯静态站点的本机时间保护不等于在线反作弊。

## 美术处理

没有新增生图请求，也没有更换模型。复用现有 gpt-image-2.5-sunburst 原画：四格序章逐格裁切；三位NPC九张表情按实际分界重切，去除相邻行头顶残片。六位Boss在地图中复用正式贴图。地图路径是界面绘制线条，人物与场景仍用已有位图。

- 裁切脚本：`scripts/recrop-story-portraits.py`，需要本地留档原图与 Pillow。
- 原图：`output/imagegen/people.png`、`output/imagegen/comic.png`（本地源码包内留档，不新增公开原图）。
- 人物裁切区域已更新到 `public/assets/v2/manifest.json`。
- 单幕素材与来源记录：`public/assets/v6/manifest.json`。
