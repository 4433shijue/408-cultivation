种一畦灵草，做一盏茶，进山历练，再学一点计算机408。

## 可以玩什么

- 九块灵田、六种作物、八种配方、三类循环委托与三档消消乐历练。
- 第一章“旧泉新声”、三处家园修缮、天气、图鉴、来访和九段友情事件。
- 四科各六道离线408种子题；答对新题增加修为，错题与复习不重复奖励。
- AI自由聊天与独立人物记忆。林疏月为成年女性同性恋，俞照与沈砚为成年男性双性恋；三人都支持友情性质的一起修炼。
- 双修需要性向相容、熟络12、三段友情事件，并由玩家明确确认恋爱。剧情使用第二人称、自愿互动与含蓄留白，不自动替玩家同意。
- 25/50分钟番茄钟或5—180分钟自定义，暂停、继续、误计时修正。静默时不调用AI；主动聊天写中途剧情，到时续写收尾。每游戏日满25分钟有效共修可加一次熟络，不直接增加答题修为。
- 多门课程、分P与时间位置书签、继续上次课程。故事书支持收藏、阅读位置、删除和TXT导出。

## 网页版 AI 怎么用

进入设置或人物页面的“道友设置”，填写自己的 HTTPS Chat Completions 兼容接口、文本模型和密钥。题库和道友配置分开，可主动复制。

网页版由浏览器直接请求所填服务商，接口必须支持跨域（CORS），允许网页来源、POST及Authorization/Content-Type请求头。本站没有公共AI密钥，也没有代转发服务。密钥仅放当前标签页内存，刷新后清除；不会上传到GitHub或写入存档。模型调用可能收费。无可用接口时，原游戏、内置题、计时、课程和已有故事仍可使用。

生成任务和结果保存在浏览器IndexedDB。同任务不重复请求，取消或失败不自动续写；关闭生成页面会中断任务，重新打开后可手动恢复/重试。计时会根据时间核算，离开时想停止计时请主动暂停。多标签页不重复奖励，另一标签页没有你的接口密钥。

课程在新标签页打开，不缓存视频，也不读取外部播放进度。B站标准视频链接保留原始链接并按记录的P和时间继续，其他站点手填独立链接与进度。

## 存档与迁移

版本3存档保留旧版角色、库存、田地、题目记录、家园与关系。旧档迁移前原样备份，不猜测未知历史答案。游戏设置中的导出包含游戏和陪伴记录；网页版生成题库可另行导出。

进度属于当前浏览器、当前网站来源。localhost与GitHub Pages不会自动共享存档：先在本地版导出，再在网页版导入。换浏览器、设备或清除网站数据前请备份。

## 本地运行与构建

需要 Node.js 24。Windows可双击“启动游戏.cmd”；或执行：

```sh
npm ci
npm run build
npm start
```

本地版使用 `http://127.0.0.1:4175/`，保留Node/SQLite服务，密钥只在服务内存；数据位于被Git忽略的data目录。

构建网页版：

```sh
npm run test:rules
npm run build:web
```

静态产物在 `dist-web`，默认基路径 `/408-cultivation/`。在其他路径部署时设置 `VITE_BASE_PATH`。应使用HTTP静态服务，不要直接用file协议打开HTML。

推送main分支会通过GitHub Actions执行规则测试、构建并部署Pages。不需要配置AI密钥或其他仓库Secrets。
